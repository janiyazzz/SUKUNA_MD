⚡ ABOUT SUKUNA MD

SUKUNA MD is a modern WhatsApp Multi Device bot built for speed, smooth performance and powerful group management.

Designed with a stylish interface and advanced admin system, SUKUNA MD delivers the perfect balance between performance and simplicity.

---

🔥 FEATURES

- 🤖 Multi Device Support
- 🔑 Pairing Code Login
- 👑 Advanced Group Commands
- 🛡️ Antilink Protection
- 🚫 Anti Delete
- ⚙️ Auto Moderation
- 🎭 Anime Features
- 📥 Downloader Commands
- 📢 Tag All / Hidden Tag
- ⚡ Fast Performance
- 🎨 Stylish Menu UI
- 🧠 Smart Admin System

1. Start the bot
2. Enter your WhatsApp number
3. Receive pairing code
4. Link device
5. Bot becomes active

📜 BASIC COMMANDS

Command| Description
.menu| Show menu
.ping| Check bot speed
.kick| Remove member
.add| Add member
.tagall| Mention everyone
.hidetag| Hidden mention
.lock| Lock group
.unlock| Unlock group
.antilink| Protect group
